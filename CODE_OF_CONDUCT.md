# Code of Conduct

Be respectful and constructive. Assume good faith, criticise ideas rather than people, and keep discussion on topic.
Harassment, personal attacks and discriminatory language are not acceptable.

Maintainers may edit or remove comments, issues and pull requests that break these rules. To report a problem,
open a private security advisory (see [SECURITY.md](SECURITY.md)) or contact the maintainer through the GitHub profile.
