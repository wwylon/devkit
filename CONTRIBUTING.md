# Contributing

devkit is a set of small Markdown rules, templates and one Claude Code plugin. Contributions that keep it small and portable are welcome.

- **Issues:** use the templates under *New issue*. For a rule that is unclear or wrong, quote the line.
- **Pull requests:** one change per PR. A rule must be true for every project that imports it; domain-specific text belongs in the consuming project, not here.
- **Style:** short bullets, one idea per line, link instead of repeating. No GitHub Actions or other hosted CI is used here; run the checks you can locally and say what you ran in the PR.
- **Versions:** changes are recorded in [CHANGELOG.md](CHANGELOG.md) under *Unreleased*; maintainers tag releases (SemVer).

By contributing you agree your work is released under the [MIT license](LICENSE).
