# plan/archive/

Completed milestone **acceptance criteria** and long task narratives. Live schedule stays in `../tasks.md` and `../NOW.md`.

| Kind | Where it lives |
|------|----------------|
| Active / todo tasks | `../tasks.md` |
| What’s next | `../NOW.md` |
| Idea decisions | `../STATUS.md` |
| Unit / regression tests | project `tests/` + CI |
| Idea A/B experiment runs | `experiments/ledger/` + experiment index |
| Chronological bench write-ups | `../optimization_log.md` |

Keep stable task IDs (T1.1, …) in archived filenames/headers so journal and ledger links still resolve.

Standard: `<portfolio-root>\devkit\rules\plan-structure.md`.
