# Algorithm / oracle doc

Read when shipping a solver, engine, or oracle write-up. Do not import this file.

Eight sections, in order:

1. **Problem** — what it solves and where it sits.
2. **Idea** — plain language.
3. **Pseudocode / key equations** — summary only; link the project spec for full math.
4. **Why it is correct** — oracle or proof sketch used in CI.
5. **Complexity / expected effect.**
6. **Project specifics** — paths and gotchas. No second copy of the spec.
7. **Measured impact** — numbers, or "pending benchmark".
8. **Sources** — references and decision records.
